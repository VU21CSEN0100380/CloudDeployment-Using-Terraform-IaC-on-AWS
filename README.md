# CloudDeployment-Using-Terraform-IaC-on-AWS
Automated AWS infrastructure provisioning using Terraform (IaC), including VPC, subnets, security groups, and EC2 instances. Configured EC2 user-data scripts to deploy a Dockerized web application. Used Terraform variables, outputs, and modular design to build reusable, scalable infrastructure following industry IaC standards.
